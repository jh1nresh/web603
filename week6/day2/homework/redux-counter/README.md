# Week 6 Day 2 Homework — Redux Counter

The two-file React Redux counter requested by the homework: the app, reducer,
store, and Provider are in `src/index.js`; the connected class component is in
`src/Counter.js`. Increment, decrement, and reset all dispatch Redux actions.

## Run

```bash
npm install
npm start
```

## Verify

```bash
npm test -- --watchAll=false
npm run build
```

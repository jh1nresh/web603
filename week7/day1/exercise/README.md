# Week 7 Day 1 Exercise — React Animation Gallery

One React application that combines the three animation demos required by the exercise. Use the navigation at the top to run each demo on its own page.

## Demos

1. [Animated bar chart using react-move](https://codesandbox.io/s/w0ol90x9z5)
2. [React Vertex — Sphere of Spheres](https://codesandbox.io/s/jn073)
3. [Collapsible Tree with VX](https://codesandbox.io/s/ww0xkyqonk)

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To verify the production build:

```bash
npm run build
```

The application uses hash-based routes so every demo can be opened directly without server-side route configuration.

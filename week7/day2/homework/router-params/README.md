# Week 7 Day 2 Homework — Router Parameters

Clicking a TV app logo sends its name through a React Router `/:id` parameter.
The child component reads the value with `useParams` and displays it below the
logos.

```bash
npm install
NODE_OPTIONS=--openssl-legacy-provider npm start
```

The `NODE_OPTIONS` flag lets the assignment's supplied CRA 4 tooling run on
current Node versions.

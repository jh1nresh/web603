# WEB603 Module 5 — Week 1 to Week 4

Notes covering the Week 1–4 submissions. The coursework itself lives in the
weekly folders of this repository; the per-week write-ups are in
`weekN/day3/shared/SUBMISSION.md`.

## Run and verify

Weeks 1–4 are consolidated into one React/Vite app:

```bash
cd ../../week4/day3/coursework-app
npm install
npm run check
npm run dev
```

Open the weekly route listed in that week's `SUBMISSION.md`.

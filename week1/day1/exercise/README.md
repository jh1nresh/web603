# Module 5 · Week 1 · Day 1 — React demos

This project rebuilds the seven in-class demos from
`Module5-Week1-Day1_Exercise.pdf`.

## Demo map

1. `Demo1/demo1.html` — Render “Hello, world!” with JSX.
2. `Demo2/demo2.html` — Pass a `name` property to a class component.
3. `Demo3/demo3.html` — Update component state with a Like button.
4. `Demo4/demo4.html` — Timer without JSX.
5. `Demo4/demo4-jsx.html` — The same timer with JSX.
6. `Demo5/demo5-1.html` — Format and render a user’s name.
7. `Demo6/my-app` — React app styled with Bootstrap.
8. `Demo7/index.html` — Add inline CSS to JSX.

## Run the static demos

From this directory:

```bash
python3 -m http.server 8080
```

Then open a demo, for example:

```text
http://localhost:8080/Demo1/demo1.html
```

## Run Demo 6

```bash
cd Demo6/my-app
npm install
npm run dev
```
